LINUX:
Run ./Linux-Setup.sh [build_system] [compiler] [config]
    - build_system: premake (default) or cmake
    - compiler:     gcc (default) or clang
    - config:       debug (default), release, or dist
    - Arguments can be in any order
    - Examples:
        ./Linux-Setup.sh
        ./Linux-Setup.sh cmake clang release
        ./Linux-Setup.sh premake gcc

Run ./Linux-Build.sh [build_system] [config] [options]
    - build_system: premake (default) or cmake
    - config:       debug (default), release, or dist
    - --bear:       generates compile_commands.json at project root (for CLion)
    - --clean:      clean the selected config before building (premake/make only; omit for incremental builds)
    - Arguments can be in any order
    - Examples:
        ./Linux-Build.sh
        ./Linux-Build.sh cmake release
        ./Linux-Build.sh debug --bear
        ./Linux-Build.sh --clean

Run ./Linux-Run.sh [build_system] [config]
    - build_system: premake (default) or cmake
    - config:       debug (default), release, or dist
    - Must match the build_system/config you built with (paths differ between them)
    - Arguments can be in any order
    - Examples:
        ./Linux-Run.sh
        ./Linux-Run.sh cmake release


WINDOWS:
Configure build settings in Windows-Config.bat:
    - BUILD_CONFIG: Debug, Release, or Dist
    - MSBUILD: path to MSBuild.exe

Run Scripts\Windows-Setup.bat [build_system]
    - (no argument): Premake — generates Visual Studio 2022 solution in Build/
    - cmake: CMake — generates Visual Studio 2022 solution in Build/

Run Scripts\Windows-Build.bat
    - Cleans and builds using MSBuild with the configured BUILD_CONFIG
    - Works with both Premake and CMake generated solutions

Run Scripts\Windows-Run.bat
    - Runs the Editor


CLION (LINUX):
1. Run ./Linux-Build.sh --bear  (generates compile_commands.json at project root)
2. Open project root in CLion
3. CLion detects compile_commands.json — open as Compilation Database project
4. Re-run --bear only when adding new files or changing include paths
